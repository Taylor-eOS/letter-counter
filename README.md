This repository contains corpus analysis scripts used as shared groundwork for two separate text-entry and encoding projects. Its purpose is to answer preliminary questions about character-level statistics in text before architecture decisions are made.<br>
One script ingests a plain-text corpus, normalises it to a small working alphabet by folding case, collapsing whitespace, and omitting rare letters, then counts bigram transition frequencies and reports which characters most commonly follow each context character. Other scripts extend this to variable-order n-gram analysis and includes a simulator that measures how much a frequency-ordered alphabet reduces expected selection effort compared to a static ordering, which is the foundational metric for the rotary text-entry project.<br>
The outputs of these scripts (character frequencies, follower distributions, and coverage statistics) informed the table design in the codec project and established the theoretical performance ceiling for the text-entry project. Neither downstream project depends on this repository at runtime. It exists only as a record of the analysis that shaped both designs.
